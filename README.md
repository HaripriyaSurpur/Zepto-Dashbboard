### ✨ Key Features & Technical Highlights
* **Custom Dark-Theme UI:** Designed with a sleek, high-contrast dark aesthetic tailored for deep analytics reporting.
* **Dynamic Interactivity:** Built with seamless cross-filtering where selecting specific regions or data columns updates all associated metrics instantly.
* **Geographical Mapping:** Integrated regional delivery mapping for spatial distribution and performance tracking.
* **Executive Navigation:** Built with custom user-flow buttons to deliver an intuitive, multi-page reporting experience.
